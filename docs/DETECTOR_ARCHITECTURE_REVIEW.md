# Detector architecture review — 2026-09-26

**Verdict:** The original vision + three text-critic jury was an expensive, correlated opinion cascade, not three independent forensic checks. Draft PR #14 replaces it with one bounded vision-language-model (VLM) screening call. That is a cost-controlled baseline, **not a validated detector**. No local labeled accuracy or false-positive measurement exists yet. Neither the old jury nor the new VLM should be used for automatic claim decisions.

This review uses vendor documentation, maintainers' GitHub repositories, and published evaluation papers. Star counts are a GitHub API snapshot on 2026-09-26; popularity is not evidence of accuracy. Commercial internals are only partly disclosed.

## Repo-specific audit

1. **Old judge/critic design:** The historical `call_critic(model_config, vlm_findings, ...)` passed only the first VLM's text to each critic. The critics never saw the pixels. Their votes therefore shared the first model's omissions and hallucinations; majority agreement was not independent corroboration. Prompts also imposed subjective rules such as clean documents implying forgery. The previous vision call disabled TLS verification (`verify=False`). That design was not scientifically defensible as a forensic ensemble. Draft PR #14 removes it.
2. **Current draft baseline:** [`backend/qwen_agent.py`](../backend/qwen_agent.py) asks one general VLM for a forced `Real`/`Fake` label and self-reported confidence. The prompt cautions against weak evidence, but the schema has no `inconclusive` class. A large JPEG is resized/re-encoded before analysis, so fine pixel and compression traces are lost. There is no independent pixel classifier, calibrated threshold, or measured false-positive rate. Treat the prose explanation as a review aid, not forensic proof.
3. **Video:** Three evenly spaced still frames in one request can miss short edits; this is not temporal modeling, face-crop analysis, or audio analysis. DeepfakeBench's preprocessing and Hive's frame-level policies illustrate why video needs its own evaluated path. The current result should explicitly state sampling coverage.
4. **PDFs:** Rendering up to three pages lets the VLM see layout but loses searchable text, object structure, digital-signature validation, and cross-field checks. A born-digital PDF, scanned claim, and AI-written text are different tasks. A visually normal invoice may still contain fabricated amounts or identities.
5. **Metadata:** The current extractor reports square dimensions, missing EXIF, editor names, date differences, and low FPS. These are common in authentic uploads and mutable. This review changes their descriptions to neutral observations and makes their risk weight zero in the single-model path. C2PA signature validation, if added, must be presented separately and never interpreted as a fraud verdict.
6. **Score:** For the draft single-model path, the numeric risk is now a visual-only transformation of uncalibrated VLM confidence; it is not a fraud probability. `MANUAL_REVIEW` remains mandatory. Historical rows may contain old scores and policy actions and need an explicit pipeline version before combined analytics are meaningful.

## What to build next, in order

1. **Ground truth and measurement:** Build a rights-cleared, provenance-tracked labeled set with authentic photos, modern generators, local edits, benign exports, scanned/born-digital PDFs, and short/long clips. Hold out generator and source families. Measure false positives on real evidence, recall, calibration/abstention, invalid responses, latency, and OpenRouter-reported cost. Include recompression, screenshots, cropping, and re-digitization: [AIGIBench](https://papers.neurips.cc/paper_files/paper/2025/hash/fb693c67f61e5321746ffce8b6fdd2d0-Abstract-Datasets_and_Benchmarks_Track.html) and [RRDataset](https://openaccess.thecvf.com/content/ICCV2025/papers/Li_Bridging_the_Gap_Between_Ideal_and_Real-world_Evaluation_Benchmarking_AI-Generated_ICCV_2025_paper.pdf) report substantial real-world generalization challenges.
2. **Separate outputs:** Return `generated_image`, `local_manipulation`, `face_deepfake`, `provenance`, and `document_consistency` as distinct optional signals, with an `inconclusive`/`unsupported` state and observed evidence. Do not collapse them into a single fraud probability.
3. **Cheap deterministic layer:** Validate C2PA on the original bytes; preserve file hashes and format. Record signed history, missing/invalid/unsupported separately. Extract PDF text, signatures, and page structure using appropriate parsers. None of these alone establishes authenticity.
4. **Specialist models behind gates:** Compare a legally usable pixel detector with the VLM on the **same** image set. Add video face crops and temporal sampling only if held-out performance improves at acceptable compute cost. Add another paid model only when independent errors and a cost-quality gain are measured.
5. **Product controls:** Key spend cap, app authentication, durable quotas, pipeline/model version in persisted records, and clear human-review UI before public scale.

The specific model, thresholds, and fusion policy remain undecided until the first labeled comparison. No accuracy or per-item cost claim follows from the local synthetic smoke tests.
